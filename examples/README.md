# Page Snapshots

These are read-only Web UI snapshots used to verify parser and CGI request logic.

- `htm/`: TP-Link Easy Smart switch at `192.168.3.10`
- `mercury-192.168.3.11/`: Mercury Easy Smart switch at `192.168.3.11`

The snapshots include VLAN pages, trunk pages, backup/restore, saving config, and the key external scripts `pvlan.js`, `qvlan.js`, and `menuList.js`.

No cookies, session IDs, or passwords are stored here.
